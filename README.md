# ГИС управления муниципальной недвижимостью

**Проект** — веб-геоинформационная система для управления муниципальной недвижимостью, объединяющая картографическую визуализацию и прогнозную аналитику.

## Основные возможности

- **Интерактивная карта** – все объекты с цветовой индикацией статусов (зелёный – аренда, красный – просрочка, синий – свободен, серый – реконструкция, жёлтый – истекает договор)
- **Карточка объекта** – подробная информация, договоры аренды, история платежей, скачивание PDF-договора
- **Аналитика** – KPI, доходность по районам и типам объектов, рейтинг надёжности арендаторов
- **Прогноз** – поступлений на 3 месяца (линейная регрессия)
- **Уведомления** – автоматические email‑оповещения о просрочках и предстоящих платежах

## 🛠️ Технологии

`Node.js` · `Express` · `PostgreSQL` · `Leaflet` · `Chart.js` · `PDFKit` · `Nodemailer`

## Локальный запуск

### Способ 1 – Docker (рекомендуемый)

1. Установите **Docker Desktop** (версия 20.10+).
2. Откройте терминал в папке проекта (где лежат `dockerfile` и `docker-compose.yml`).
3. Выполните:
   ```bash
   docker-compose up --build
   ```
4. После сборки откройте браузер и перейдите по адресу:
   `http://localhost:3010`
5. Остановка контейнеров: нажмите Ctrl+C или выполните:
   `docker-compose down`

Способ 2 – Ручной запуск (без Docker)

1. Установите Node.js 18 и PostgreSQL 15.
2. Импортируйте дамп базы данных:
   `psql -U postgres -p 5432 -f immovables.sql`
   (при необходимости укажите свои параметры подключения)
3. Установите зависимости:
   `npm install`
4. Запустите сервер:
   `node server.js`
5. Откройте браузер по адресу:
   `http://localhost:3000`

**Важно**: в server.js по умолчанию настроено подключение к удалённой БД (82.179.9.27). Для локальной БД измените параметры подключения в коде (хост localhost, свой пароль и порт).

Альтернативный способ – готовый Docker-образ
Если у вас есть файл municipal-gis.tar, выполните:

`docker load -i municipal-gis.tar`
`docker run -p 3010:3010 municipal-gis`

Сервер станет доступен на http://localhost:3010
